BestStore is an online electronics shopping platform designed to provide users with an easy and efficient way to browse and purchase electronic devices. This project is built using ASP.NET MVC and features a seamless integration with a mobile application developed in Flutter.

Features

Product Catalog: 
View a wide range of electronic devices with details such as name, brand, price, description, and images.

User Authentication: Secure login and registration system for users.

Cart Management: Add, update, and manage cart items stored in sessions or cookies.

Mobile Application: Companion Flutter app for enhanced user experience on mobile devices.

Social Media Integration: Links to WhatsApp, Facebook, Instagram, and email for customer support.

Technologies Used

Backend
ASP.NET MVC
Entity Framework
SQL Server

Frontend
HTML5, CSS3, and JavaScript
Bootstrap for responsive design
